Freqtrade 出入场信号颜色说明

记录 FreqUI 图表上各种箭头、矩形、形状、颜色的含义。FreqUI 在同一张 K 线图上叠加了多组图层。

三个图层 / Three Layers

FreqUI 把策略和交易的相关信息以三种独立图层叠加在 K 线图之上：

图层 / Layer 含义 / Meaning
策略信号 / Signal Layer 策略想开仓/平仓的位置，每根 K 线都可能出现，不一定真的成交
实际订单 / Order Layer 数据库中已成交（或挂单中）的订单记录，对应真实资金动作
止损线 / Stoploss Line 仅持仓期间显示的红色横线，标识当前止损价位

核心区别： 信号箭头只看 dataframe 列是否等于 1，订单箭头才代表真实交易。看到信号没看到订单 = 信号被冷却、confirm_trade_entry、已有持仓等机制挡住了，没真的下单。

上面这张图显示出了开多、开空的策略信号（亮绿色），以及开多、开空的订单信号（单三角形+单矩形蓝色，紫色），以及部分平仓的平空、平多的信号（双三角形蓝色，紫色）。

策略信号箭头 / Signal Markers

每种入场/出场信号有独立的形状和颜色：

预览形状颜色信号含义
三角形向上 亮绿色 多头入场信号 enter_long = 1
三角形向下 亮绿色 空头入场信号 enter_short = 1
菱形 金黄色 多头出场信号 exit_long = 1
图钉形（水滴形） 金黄色 空头出场信号 exit_short = 1

注意：

  • 多空入场都用同一种亮绿色，靠形状方向区分
  • 这些信号不代表交易已发生，只是策略在这根 K 线上把对应的 dataframe 列设成了 1

实际订单标记 / Order Markers

订单标记由两类组合形状构成，颜色按多空区分：

  • 多单订单 —— 一律使用蓝色
  • 空单订单 —— 一律使用紫色

形状分两种：

形状一：矩形 + 三角形 组合

用于一笔交易的首单（开仓）和末单（最终平仓）。视觉上就是一个矩形紧贴着一个三角形。

预览颜色方向含义旁边文字
蓝色 三角向上 多单开仓 Long
蓝色 三角向下 多单最终平仓（这笔交易收盘） +20.83% 类盈亏百分比
紫色 三角向下 空单开仓 Short
紫色 三角向上 空单最终平仓（这笔交易收盘） +xx% 类盈亏百分比
如果订单是限价挂单中（尚未成交），label 文字会变成 `Long (open)` / `Short (open)`，形状颜色不变。

形状二：双三角 叠加

用于一笔交易中间的所有调仓订单——分批止盈（partial_exit）、分批加仓（DCA）等。视觉上是两个三角形上下紧贴叠在一起。

预览颜色方向含义
蓝色 双三角向下 多单减仓（分批止盈、partial_exit）
蓝色 双三角向上 多单加仓（DCA 加仓）
紫色 双三角向上 空单减仓
紫色 双三角向下 空单加仓

中间调仓不带文字 label，只能点击弹窗看 Order-Tag 字段确认是 partial_exit 还是其他原因。

弹窗字段对照 / Tooltip Fields

鼠标移动到指定成交k线会弹出 tooltip，关键字段含义如下：

字段 / Field 含义 / Meaning
第一行 Long entry / Long exit / Short entry / Short exit 表示这是首单或末单（矩形+三角组合）
第一行 Long adjustment / Short adjustment 表示这是中间调仓（双三角组合）
Enter-tag 入场标签（策略 populate_entry_trend 中标注的入场原因）
Order-Tag 订单标签（如 partial_exit 表示分批止盈）
Exit-Tag 出场标签（如 trailing_stop_exit_max_xx% 表示移动止损平仓），仅末单显示
Order Price 该订单的成交价
顶部数字（如 -64.413 USDT） 该订单对应的资金变化（含正负号）

如果不确定一个订单标记是”首单/末单”还是”中间调仓”，弹窗第一行的关键字——entry/exit 是首末单，adjustment 是中间调仓。

持仓止损线 / Stoploss Line

仅在该交易仍处于持仓中时显示，平仓后会消失。

元素 / Element 描述 / Description
形态 半透明红色横线
高度 当前止损价（stop_loss_abs）
横向范围 从开仓时间画到平仓时间（未平仓则画到当前）

完整对照速查表 / Quick Reference

预览看到的颜色与形状含义
亮绿色三角向上 多头入场信号
亮绿色三角向下 空头入场信号
金黄色菱形 多头出场信号
金黄色图钉形 空头出场信号
蓝色矩形+三角向上 + Long 文字 多单实际开仓
蓝色矩形+三角向下 + 盈亏百分比 多单实际平仓（一笔交易结束）
蓝色双三角向下 多单减仓（分批止盈、partial_exit）
蓝色双三角向上 多单加仓（DCA）
紫色矩形+三角向下 + Short 文字 空单实际开仓
紫色矩形+三角向上 + 盈亏百分比 空单实际平仓（一笔交易结束）
紫色双三角 空单调仓（具体方向看是减还是加）
半透明红色横线 持仓中的止损价位
